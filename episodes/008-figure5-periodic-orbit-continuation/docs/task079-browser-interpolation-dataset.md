# TASK-079 browser interpolation dataset

TASK-079 builds the schema-valid display/interpolation layer for Figure 5 from the authoritative Episode 008 production artifacts.  It does not create new continuation solves and does not use the lower-panel heatmap as a data source.

## Artifacts and commands

The browser/display artifact is:

- [`../outputs/figure5_browser_interpolation_dataset.json`](../outputs/figure5_browser_interpolation_dataset.json)

Regenerate or verify it with:

```bash
uv run python episodes/008-figure5-periodic-orbit-continuation/scripts/generate_figure5_browser_interpolation_dataset.py
uv run python episodes/008-figure5-periodic-orbit-continuation/scripts/generate_figure5_browser_interpolation_dataset.py --check
uv run python episodes/008-figure5-periodic-orbit-continuation/scripts/validate_production_artifacts.py \
  episodes/008-figure5-periodic-orbit-continuation/outputs/figure5_browser_interpolation_dataset.json
```

## Interpolation decision

The interpolation contract is `pchip-shape-preserving-log-period-safe-topology-v1`: when enough authoritative nonlinear points exist inside one safe connected segment, interpolation must be shape-preserving PCHIP on `log(P)`, and it must pass the documented along-slice and withheld-slice holdout gates.

The current TASK-075 production ledger has one accepted nonlinear native adaptive point, `spine-210K`, and 297 unresolved requested targets.  Therefore TASK-079 emits **no interpolated nonlinear browser values**:

- along-slice holdout is `not_evaluated` because no slice has the required three accepted nonlinear source points;
- withheld-slice holdout is `not_evaluated` because fewer than three temperature slices have accepted nonlinear source points;
- no interpolation crosses Hopf boundaries, unresolved targets, instability checkpoints, tripwire or near-Hopf stops, or multivalued tripwires;
- unresolved production targets remain `validity.status = resolution_unresolved` with null display periods.

This satisfies the TASK-069/TASK-075 explicit-gap policy: gaps are visible browser records, not filled display values.

## Browser record classes

The artifact is a production-v1 `browser-display-dataset` and currently contains these display categories:

| Category | Meaning |
| --- | --- |
| `solved_native_nonlinear` | Accepted TASK-075 native nonlinear continuation value.  It appears once for the upper period map and once for the lower T=210 K nonlinear slice. |
| `validated_interpolated_nonlinear` | Reserved for future holdout-passing PCHIP `log(P)` values; current count is zero. |
| `gap_unresolved_native_target` | Requested TASK-075 target with `resolution_unresolved`; null display period and no interpolation fill. |
| `hopf_limit_explicit_gap` | TASK-076 Hopf-boundary policy record; null regular-orbit display period. |
| `invalid_outside_hopf_domain` | Display mask records outside the Episode 006 lower/upper Hopf-locus bracket. |
| `linearized_equilibrium_T210K` | TASK-074 independent T=210 K equilibrium-linearized period rows. |
| `image_derived_comparison_pending` | TASK-079 was generated before TASK-063 digitized Figure 5 data were available, so it exposes the external-comparison channel without fabricating image-derived values. |

Every browser record carries units, coordinate convention metadata, exactly one schema-valid validity/source flag pair, and links to its authoritative source records or comparison handoff task.

## Lower-panel provenance

The lower panel deliberately uses two independent sources:

1. the nonlinear record comes directly from the accepted TASK-075 native continuation point `task075-point-spine-210K`;
2. the red equilibrium-linearized curve comes directly from all TASK-074 `t210_linearized_period_curve.json` rows.

The lower panel is **not** generated by resampling or slicing the upper heatmap.  TASK-079 records this as `lower_panel_source_policy.heatmap_resampling_used = false`.

## Digitized paper policy

TASK-079 was generated before the TASK-063 digitization artifacts existed, and it is not allowed to invent image-derived comparison data. The artifact therefore contains only `not_evaluated` external-comparison placeholder records. A later paper-comparison/browser task can incorporate `outputs/paper_figure5_digitization.json` and its CSV overlays as real `external_digitized_paper_comparison` records with documented uncertainty. Agreement with digitized pixels cannot override native continuation gates, Floquet diagnostics, or IVP validation.
